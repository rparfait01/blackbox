# Rhezia — brand package

**Name:** Rhezia *(ray-ZEE-ah)* — from Gk. παρρησία, *parrhesia*: to speak the truth
without fear, at personal risk, by the one with least power to the one with most.

## Files

| File | Use |
|---|---|
| `RHEZIA_BRAND_GUIDE.html` | The guide. Open in a browser. Colors, mark, type, voice, naming, site copy. |
| `rhezia-mark.svg` | Primary mark. Midnight Ink stroke, Archival Brass terminus. |
| `rhezia-mark-reverse.svg` | For dark grounds. Parchment stroke, brass terminus. |
| `rhezia-mark-mono.svg` | One color, inherits `currentColor`. For favicons, embroidery, stamps, single-color print. |
| `rhezia-icon.svg` | App icon. Reverse mark on Midnight Ink, 22.5% radius. |

## Color

**Brand** — Midnight Ink `#071A2B` · Archival Brass `#C79A42` · Warm Parchment `#F5F1E8`

**Product** — True Black `#000000` · Signal Amber `#e89a00` · Alert Red `#D6453C` ·
Stillpoint Teal `#4fd1a5` *(facade only, never brand)*

Amber and red are now separate. Amber marks the record; red marks a warning. Nothing
should have to carry both meanings.

## Type

Display **Jost** 400, tracking .14em — wordmark and headlines only
Body **IBM Plex Sans** 400/600
Utility **IBM Plex Mono** 400 — timestamps, coordinates, hex, verification outcomes

## Before anything ships

1. Confirm `RHEZIA` clear in IC 009 and IC 042
2. Register `rhezia.com` and `rhezia.app`
3. File the trademark
4. Then the rename brief

Do not touch code before 1–3. A blocked name means renaming twice.
