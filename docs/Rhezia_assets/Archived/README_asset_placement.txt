BLACK BOX — SITE ASSETS & WHERE EACH GOES (Squarespace)
========================================================
Every asset is provided as both SVG (crisp, scalable) and PNG (drop-in for Squarespace).
Squarespace tip: use PNG for backgrounds; SVG or PNG for the logo.

------------------------------------------------------------
1. blackbox_mark  (transparent — mark only)
   → Site LOGO. Upload in: Design → Logo & Title → Logo Image.
   → BEST APPROACH: upload the mark here, and type "BLACK BOX" as the Site Title
     text — Squarespace renders the wordmark in your chosen web font, crisp.

2. blackbox_icon_dark  (dark rounded square)
   → FAVICON / browser tab icon. Design → Browser Icon (Favicon). Use the PNG.
   → Also your social share icon / app icon if you wrap it later.

3. blackbox_lockup  (mark + "BLACK BOX" wordmark, horizontal, transparent)
   → Use ONLY if you want a baked-in logo+wordmark image instead of separate
     logo + text. The wordmark font is a mono fallback here; for exact type,
     prefer option 1 (mark + Squarespace text title).

------------------------------------------------------------
4. blackbox_hero_bg  (2400x1350, dark, heartbeat + ghost mark)
   → HERO section background. Replace the stock gym photo:
     Edit hero section → Background → Image → upload blackbox_hero_bg.png.
   → Text sits on the LEFT (the image is faded there for legibility).
   → Set overlay/opacity low or none — it's already dark.

5. blackbox_signal_band  (2400x400, heartbeat trace on black)
   → Thin DIVIDER between sections, or a slim section background.
     Optional. Adds the signal motif as a break.

6. blackbox_custody_emblem  (1000x1000, cube-in-ring + keyhole)
   → Accent image for the "What it protects / The record" section.
     Optional. Use as an inline image beside the custody copy.

------------------------------------------------------------
COLORS (for matching Squarespace theme):
   Background ink:  #0a0c10
   Panel:           #141a24
   Text (bone):     #eae7e0
   Muted text:      #8b95a4
   Signal red:      #e23625   (use sparingly — accent only)

TYPE (set in Squarespace fonts):
   Headings:  a serif (e.g., IBM Plex Serif) or keep template serif
   Body:      IBM Plex Sans / clean sans
   Labels:    IBM Plex Mono / any monospace  (for the technical/label feel)
