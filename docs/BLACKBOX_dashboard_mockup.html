The separation is enforced on the server, not by hiding buttons. Below is what happens when a role reaches for something outside its scope — the server refuses. This is a live demonstration of the boundary, not a screenshot.

Data custody. This console shows operational counters only — enrollments, code status, activation counts.
Incident records are zero-knowledge encrypted and belong to the survivor. No role here — including Operator — can view, unlock, or export incident content.
