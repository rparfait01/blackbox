01 System architecture Triggers fire signals. Bridges (phone or device) relay them. Cloud workers process and persist. Outputs reach humans through messaging and dashboards.
⚡ Trigger Layer
Phone-side
Lite tier · always available
Manual button, voice keyword, shake, fall detection, check-in timeout.
v0 BLE Button
Off-the-shelf · Flic 2 white-label
Single-press activation. Coin cell. 12-month battery. $79–99.
v1 Sentinel Cube
Custom · branded · deniable
Tamper · shock · deadman pin · capacitive squeeze. $129–179.
v2 Recorder Puck
Custom · evidence-grade
360° camera + 4-mic array + onboard SSD + tamper + last-gasp. $349–499.
⇄ Bridge Layer
PWA on User's Phone
Always · capture or relay
Captures audio/video/GPS (Lite + v0 + v1).
Relays high-throughput stream from v2 device.
Local transcription, BYOK AI classification.
Optional LTE-M (v2 only)
Direct-to-cloud fallback
When phone is destroyed or out of range, device transmits low-bitrate audio + GPS directly to cloud via cellular IoT.
☁ Cloud Layer
Cloudflare Workers
Edge · routing · auth
Event creation, HMAC validation, token minting, AI proxying when needed.
R2 Object Storage
Media · zero egress
Audio + video chunks. Signed URLs for playback. 10GB free tier.
D1 SQLite
Metadata · audit · events
Event records, device registry, audit ledger, share tokens.
Durable Objects
Realtime · websocket
Live dashboard sessions. Each event has its own DO instance for state.
📡 Output Layer
LINE / Telegram Bots
Free · instant · international
Rich messages with location, audio preview, dashboard link.
Live Dashboard
PWA · shareable · token-scoped
Contact, Authority, Public view tiers. Share button propagates exponentially.
Web Push + Email + SMS
Fallback channels
Resend/SES email, Twilio SMS (paid), Web Push (free).

03 Actors — who interacts with what Four roles. Each sees a different view of the same event. Permissions cascade down the share chain.
①
Owner
The User
Sees: Always-dormant home view. Hidden gesture reveals full dashboard.
  • Configure contacts, AI provider, triggers
  • Activate manually or via device
  • Cancel with hold or duress phrase
  • Review history of activations
  • Revoke any share token
②
Recipient
Designated Contact
Sees: LINE/Telegram alert, then full live dashboard.
  • Receive instant rich notification
  • Open live dashboard via link
  • Listen to audio, see location updating
  • Share to authorities (one-tap)
  • Acknowledge via "I'm responding"
③
Responder
Authority
Sees: Dispatch-formatted view. Optimized for CAD entry.
  • One-line summary copyable to CAD
  • Multi-format coordinates
  • Live audio with timestamp scrub
  • Callback info for witness
  • "I am responding" updates chain
④
Network
Public / Re-shared
Sees: Redacted public view. Designed for amplification.
  • General area (500m radius)
  • Anonymized summary
  • Redacted audio (identifiers muted)
  • Viewer count visible
  • Can flag self as nearby helper
04 End-to-end activation flow From trigger to resolution. Each step has a target time. The whole loop from activation to contact-receives-link is under 5 seconds.
01
T+0s · trigger

Activation fires

User taps button, shakes phone, pulls deadman pin, or device tamper triggers. Single haptic on the device confirms registration. Phone screen unchanged.

02
T+0.2s · capture begins

Recording starts immediately

Audio and (where available) video begin recording locally. GPS streaming starts. Local keyword classifier and transcription begin in parallel. BYOK AI receives first text segment within 2 seconds.

03
T+1s · event opens

Cloud event created, link minted

PWA POSTs to Cloudflare Worker. Worker creates event record in D1, mints the shareable URL (blackbox.app/live/a7f3-8e2c-4d), returns signed upload URLs to PWA.

04
T+2s · alerts dispatch

LINE / Telegram messages fire

Bot Worker pushes rich Flex Message (LINE) or formatted message (Telegram) to all primary contacts. Includes location, 3-second audio preview, dashboard link, quick reply buttons. Web Push goes to any registered devices.

05
T+3-5s · contact opens

Contact taps link, dashboard loads

Contact's phone vibrates, they tap. Dashboard PWA opens in browser. Live audio begins playing within 5 seconds total. Map, transcript, AI summary update continuously via Durable Object websocket.

06
T+5-30s · spread

Contact taps SHARE

Emergency dispatch block sits at top of share sheet. One tap dials 110 (Japan location detected) and copies link to clipboard. Below, share to LINE / SMS / Twitter / family group chats. Each share creates a sub-token.

07
T+30s-resolution · response

Authorities receive context, respond

Dispatcher opens authority-tier view from clipboard link. Sees structured dispatch summary, coordinates in three formats, live audio, callback to witness. Taps "I am responding" — that ack propagates to all viewers and the user (if they're checking via hidden gesture).

08
resolution · 6h cleanup

Stand down, tokens expire, evidence preserved

User cancels (hold 3s) or authority marks resolved. All share tokens expire automatically 6 hours later. Audio + video + audit ledger preserved per user's retention setting (default 30 days). Cryptographically signed evidence package downloadable.
