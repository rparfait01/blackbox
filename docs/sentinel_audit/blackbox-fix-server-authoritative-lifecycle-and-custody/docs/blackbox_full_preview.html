EACH SHARE IS LOGGED · TOKENS AUTO-EXPIRE 6H AFTER EVENT ENDS · USER CAN REVOKE ALL LINKS

Emergency dispatch sits above the standard share menu. Tapping it dials the local emergency number and puts the link in the clipboard — so when dispatch picks up, the caller pastes the link and dispatch sees everything.

01

Activation creates the link

The instant the user triggers, the backend mints blackbox.app/live/a7f3-8e2c-4d. Token is short, memorable, scoped to this single event.

02

Contact receives the link via Telegram instantly

Bot delivers a rich message with location pin, audio clip, and the live link. No app install required for the contact — Telegram is already on most phones, and it's free.

03

Contact taps Share — native sheet opens

Emergency dispatch sits at the top. Below it, every messaging and social app on the phone. One tap per destination. Link copied, link sent, link spreading.

04

Each recipient sees the same live dashboard

Different tokens, different tiers — full data for designated contacts, dispatch-formatted for authorities, summary for public amplification. Each can re-share. The link spreads at network speed.

05

The user can revoke all of it with one button

After the event resolves, the user can wipe every active token in one tap. Or let them expire automatically 6 hours after stand-down. Audit trail of every share is preserved for evidence.

04 The shared link recipient — three viewer tiers Same URL pattern, different access tiers. Original contact has full access. Authority links unlock dispatch-formatted data. Public links are redacted for social amplification.

05 Three things this matrix makes clear
●

The user's phone never changes

Same dormant view across all three tiers. Same hidden gesture. Same "ARMED · LISTENING." What changes is which device is paired, and that's confined to one line on the home screen.

●

Each hardware tier visibly upgrades the dashboard, not the workflow

The contact's workflow — open link, see live data, tap share — is identical regardless of hardware. v2 adds 360° video, multichannel audio, direction of arrival, and device-side storage. Same interface, richer content. Upgrading hardware is upgrading evidence quality, not learning a new system.

●

Sharing is the product's superpower

The SHARE button is the most prominent action on every dashboard. Emergency dispatch sits above social channels in the share sheet. Every share creates a new token, lower-privileged. The link spreads at network speed; the data stays in one place. Authorities receive a dispatch-formatted view, social amplification gets a redacted view, contacts get the full data — same URL pattern, different access.
