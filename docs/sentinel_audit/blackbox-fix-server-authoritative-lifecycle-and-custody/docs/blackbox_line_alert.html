Why LINE specifically (and not just SMS / Push)

95% Penetration in Japan
Almost every smartphone owner in Japan has LINE. No friction to install, no carrier dependencies. If the contact is reachable at all, they're reachable on LINE.
Free, Instant, International
LINE Messaging API has a generous free tier (1,000 messages/month per account). No SMS costs, no Twilio overhead, delivery is instant regardless of carrier.
Rich Format Out of the Box
LINE Flex Messages support maps, audio playback, structured data, quick reply buttons — all in one notification. SMS is a 160-character text. The format gap is significant.
Verified Business Badge
LINE Official Account verification shows the green badge. Recipients know the alert is legitimate, not a phishing attempt. Critical for authority forwarding.
