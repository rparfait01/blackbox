Module map

● Open — phone green, BYO next
donePhone-side covert hold-to-activate behind the Stillpoint facade.

MODULE 03

Capture

● Green
doneAudio + GPS capture streaming to coordinator; live transcript; origin snapshot latch.
deferredVideo — gated on camera hardware (pendant/glasses); not a v0 dependency.
MODULE 04

Alert Lifecycle

● Green core
doneServer-authoritative state machine: dormant → active → standdown-requested → secured. Refresh is not a close.
openClosure upgrade: symmetric push-button dual-consent + order-independent queue; gesture-as-signal duress (tap = signal, hold 3s = clean).
MODULE 05

Notification & Cascade

● Green
doneSequential ~15s cascade in priority order; SMS / LINE / email channels; per-channel delivery records; cascade halts on claim.
noteChannels are swappable — adding one never touches call sites.
MODULE 06

Coordination

● Green
doneFirst-responder-wins coordinator election (claim on deliberate POST only); coordinator / notified / dispatch role views; share-with-authorities; dispatch handoff.
MODULE 07

Custody & Data

● Green core
doneD1 operational state; R2 evidence storage; write-once closure status report; audit log.
openIntegrity signing keys + public-key publication (deploy runbook); evidence-package export verify.
